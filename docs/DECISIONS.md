# Aftermark Decisions

- Aftermark is Skill-first before hosted SaaS.
- Codex built-in image generation is the default generation path; normal Skill use requires no creator API key or automatic provider fallback.
- AI generates the transparent outer-art ingredient, not the final record.
- The original center image and its protection are deterministic.
- Literal user text, marginal phrases, collectible metadata, final composition, and share card are application-owned.
- The current production scope is `neon_scribble`, `medium`, `classic`, with `text_led` and `motif_led`.
- OpenAI, Gemini, FLUX, and provider-benchmark infrastructure remain frozen for future BYOK/hosted exploration.
- `README.md` remains held for an explicitly approved public-release update.
- One concept has one source of truth; prefer executable contracts and avoid speculative abstractions.
