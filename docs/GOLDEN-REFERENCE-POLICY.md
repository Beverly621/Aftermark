# Aftermark Golden Reference Policy

## Important distinction

The old 18-provider dry-run matrix/contact sheet is **not** a Golden Reference library.

It is benchmark infrastructure and should never become runtime aesthetic input.

## Layer 1 — Written art direction

This is the primary source of truth and should be read by Codex on each generation:

- opaque acrylic/POSCA-like marker
- real glossy vinyl below matte/opaque marks
- visible grooves
- irregular asymmetric composition
- R00-level medium richness
- roughly 65% micro marks + one larger thematic motif
- source-derived palette
- TEXT-LED / MOTIF-LED grammar
- deterministic user text
- no chalk/crayon/vector/sticker-pack look
- playful, not kindergarten/franchise-kawaii

Store rules in files such as:

```text
references/neon-scribble.md
references/composition-grammar.md
references/lettering.md
references/material-classic.md
references/negative-rules.md
```

## Layer 2 — Curated visual anchors

Images are optional but useful when they are clean and role-labeled:

- `GOLDEN_COMPOSITION`
- `PAINT_PHYSICALITY`
- `CLASSIC_VINYL`
- `TEXT_LED_LAYOUT`
- `MOTIF_LED_LAYOUT`

Do not pass an unlabeled moodboard.

## Public repo rule

Only ship images safe to redistribute:

Allowed:
- Aftermark-owned/generated samples
- CC0/public-domain
- explicitly licensed assets
- original diagrams

Do not ship:
- random Pinterest/Behance/Etsy images
- copyrighted screenshots without rights
- private user photos
- benchmark `NOT RUN` sheets

## v0.1 recommendation

Text rules are mandatory.

Visual anchors can be added during Task 2C03 after we create a clean, owned/licensed set.

The runtime should not be blocked on old research images.
