# Aftermark · Neon Scribble Reference Synthesis v1.1

## Purpose

This document consolidates the first two human review rounds into a practical visual direction for **Task 02-B — Connect and Tune the Real Neon Scribble Generator**.

The original review forms remain the source of truth:

- `EVALUATION_FORM_COMPLETED_v1.md`
- `EVALUATION_ADDENDUM_COMPLETED_v1.md`

### Important note about the first review's grade column

The first completed form contains values such as `A1`, `A2`, `A5`, `A6`, `B1`, `B3`, and `C1`, although the requested scale was A/B/C.

To avoid silently inventing a scoring system, this synthesis does **not** interpret the numeric suffixes as a formal ranking.

Instead, each reference below is assigned a **normalized role** based on the user's written comments. The original labels are preserved in the source form.

# 3. Neon Scribble Visual Grammar v1.1

## 3.1 Physicality

The outer artwork should feel physically applied to a real record.

Primary medium:

- opaque acrylic paint marker
- POSCA-like paint pen

Required physical cues:

- pigment sits above the surface
- subtle edge irregularity
- pressure variation
- repeated strokes
- slight wobble
- surface grooves remain visible beneath / between marks
- vinyl reflection and paint response differ

Avoid:

- vector-perfect strokes
- pure emissive neon
- chalk-dominant rendering
- wax-crayon-dominant rendering

---

## 3.2 Composition

Core principle:

**irregular, rich, asymmetric, personally marked**

Avoid:

- equal quadrants
- perfect radial balance
- repeated icon spacing
- mechanical sticker grids

For medium / `LEAVE A TRACE`:

- preserve R00 richness as baseline
- keep visible vinyl breathing room
- allow one larger visual motif
- use many small marks around it

Suggested semantic ratio:

- roughly **65% small symbols / micro marks**
- plus **one larger concrete thematic motif**

This is a compositional guideline, not a strict numeric validator.

---

## 3.3 Center image

The original user image remains protected.

Keep:

- circular center label
- recognizable original source
- no AI redraw
- no face replacement
- no central-image semantic reinterpretation

The center is not decorative filler.
It is the personal identity anchor of the record.

---

## 3.4 Lettering

Preferred direction:

**artistic lettering**

Use three functional layers:

### Hero lettering
- 0–1 major text moment
- may curve around or interact with the vinyl circle
- expressive
- marker-based
- may use user message or a selected key word

### Note lettering
- 1–2 restrained AI phrases
- short
- secondary
- image/theme relevant

### Micro writing
- catalog-like handwritten marks
- tiny numbers
- arrows
- underlines
- circles
- crossed-out strokes

Avoid making all three layers use the exact same font/hand.

---

## 3.5 AI text

Keep:

- user message = primary personal text
- AI = 1–2 short phrases only

AI phrases should not sound like:

- motivational quote generators
- fake diary entries
- fake personal memories
- emotional confessions

AI should sound like marginal visual notes.

---

## 3.6 Color

Preserve the existing source-informed principle:

- ~65% source-derived palette
- ~25% neutral structural colors
- ~10% surprise accent

New emphasis from review:

- colors should feel vivid enough to sit visibly above the record
- U02's muted/crayon darkness is too weak
- saturation may increase when necessary to preserve acrylic-marker clarity

Avoid:

- equal-weight rainbow color distribution
- childish multi-color overload

# 8. Task 02-B Implications

The next execution plan should treat Neon Scribble as a structured art-direction system.

Recommended generation logic:

```text
1. Analyze user image
   - palette
   - concise visual motifs

2. Decide composition plan
   - irregular distribution
   - 65% micro motifs
   - optional one larger thematic motif
   - protected center

3. Decide lettering plan
   - artistic hero lettering if used
   - user message
   - 1–2 AI marginal phrases

4. Decide physical material plan
   - Classic first
   - grooves + gloss deterministic where possible

5. Generate / compose outer art
   - acrylic-marker physicality
   - no central redraw

6. Deterministically composite
   - original center image
   - critical metadata
   - final export
```

## Strong recommendation

Separate:

- physical record material
- AI doodle/paint layer
- center photo
- deterministic text/metadata
- sleeve/reveal UI

Do not ask one image-generation call to solve every layer.
